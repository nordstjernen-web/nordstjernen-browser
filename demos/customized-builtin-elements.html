Customized built-in elements new

A customized built-in extends a real HTML element instead of a bare HTMLElement. Nordstjernen now upgrades <button is="like-button"> through the full custom-element lifecycle while keeping every native button behaviour.

Live demo

These are ordinary <button> elements with is="like-button". Click to toggle — the count is driven by the custom class's connectedCallback and a click reaction.

How it is defined

class LikeButton extends HTMLButtonElement {
  connectedCallback() {
    this.count = this.hasAttribute('liked') ? 1 : 0;
    this.render();
    this.addEventListener('click', () => {
      this.toggleAttribute('liked');
      this.count = this.hasAttribute('liked') ? 1 : 0;
      this.render();
    });
  }
  render() { this.dataset.likes = this.count; }
}
customElements.define('like-button', LikeButton, { extends: 'button' });
